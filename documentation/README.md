This documentation will be used and published to https://www.aksaracms.com/pages/documentation

Documentation pages are organized by language first, then by section:

```text
documentation/{language}/{section}/{page}.md
```

Examples:

```text
documentation/en/method/addButton.md
documentation/id/method/addButton.md
documentation/id/model/affectedRows.md
```

Use the same page name across languages so translated pages can be matched
reliably. If a page is not available in the requested language, the
documentation renderer should fall back to the English page.
