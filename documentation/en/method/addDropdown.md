### Usage Sample
`$this->addDropdown('foo', 'bar');`

`$this->addDropdown('baz', 'qux');`

**You can use this method in groups as below:**
```php
$this->addDropdown([
    'foo' => 'bar',
    'baz' => 'qux'
]);
```
