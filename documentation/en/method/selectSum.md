`selectSum($foo, $bar)`

**Parameter**
* **$foo** [`string`] *the detail related to the variable;*

### Usage Sample
`$this->selectSum('foo', 'bar');`

`$this->selectSum('baz', 'qux');`

**You can use this method in groups as below:**
```php
$this->selectSum([
    'foo' => 'bar',
    'baz' => 'qux'
]);
```
