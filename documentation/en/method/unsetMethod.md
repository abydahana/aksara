### Reference
`unsetMethod($foo, $bar)`

**Parameter**
* **$foo** [`string`] *the detail related to the variable;*
* **$bar** [`string`] *the detail related to the variable.*

&nbsp;

### Usage Sample
`$this->unsetMethod('foo', 'bar');`

`$this->unsetMethod('baz', 'qux');`

**You can use this method in groups as below:**
```php
$this->unsetMethod([
    'foo' => 'bar',
    'baz' => 'qux'
]);
```
