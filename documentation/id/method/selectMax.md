### Referensi
`selectMax($foo, $bar)`

**Parameter**
* **$foo** [`string`] *keterangan terkait variabel;*
* **$bar** [`string`] *keterangan terkait variabel.*

&nbsp;

### Contoh Penggunaan
`$this->selectMax('foo', 'bar');`

`$this->selectMax('baz', 'qux');`

**Anda juga dapat menggunakan metode ini secara berkelompok seperti berikut:**
```php
$this->selectMax([
    'foo' => 'bar',
    'baz' => 'qux'
]);
```
